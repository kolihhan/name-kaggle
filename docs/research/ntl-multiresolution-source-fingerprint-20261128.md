# Multiresolution source-conditioned fingerprint (MSF) — pre-result contract

Goal: standalone full 18-class identity attribution, not an added PB115 or v36 rule. Use the public ATLAS source-conditioned Qwen3-8B asset only if its 18 labels, checkpoint, base and rights are admitted. Existing v36 contains ATLAS-family scoring, so the novelty being tested is the readout of the token-by-source log-probability matrix, not the underlying public checkpoint.

Hypothesis: local identity evidence persists across segments but document mean likelihood is contaminated by high-influence spans. Alternative: robust segment summaries remove useful rare identity evidence, or model source bias dominates both. Fixed control: source with highest masked document mean logp. Fixed candidate: mean across scales of median contiguous-block relative logp; scales 2,4,8 only if >=8 tokens per block; <16 tokens excluded and coverage reported. No threshold/weight fitting. Per-token shared difficulty cancels, but source-specific offsets do NOT; global centering cannot be claimed to fix calibration. Record global/local disagreement, BA, paired rescues/regressions, per-source coverage, time, and same-row prompt-cluster intervals. A synthetic test only proves arithmetic, not the hypothesis. Real model execution requires admitted full18 cohort with independently established provenance/rights and GPU authorization or measured feasible CPU runtime. Compare against existing ATLAS readout as well if its actual fitted head assets can be admitted. No prediction of .760 or submission until independent actual full18 comparison and runtime gate; preserve .718.

## CPU diagnostic timeout and one engineering-only optimization
Run 46105651092 completed only 3/18 before the 55-minute timeout, at 810.26, 790.28 and 817.30 seconds; no completed BA. Both runners reported 15 GiB RAM and 3 GiB swap, while the 8.19B BF16 weights alone occupy approximately 15.26 GiB. Memory pressure is plausible, not demonstrated as the root cause. Original code reads the full 151k-vocabulary output projection repeatedly for each source and 16-token chunk. Replaced only the full-vocabulary projection with a vocabulary-tiled, all-source batched FP32 log-sum-exp reduction. No new model or classifier change, no quantization, no fit; preserve all 18 source conditions and identical frozen cohort. Verify dense equivalence on synthetic FP32/BF16 tests and on 16 actual target positions from the same first hidden state (max abs <= .05). Report separate backbone/head timing and disk reads/page faults. The retry uses the original 55-minute limit and stops without BA if conservative extrapolation exceeds the 2400s inference budget. No partial cohort accuracy. A passed CPU diagnostic still does not establish hidden-scale feasibility or independent performance.
