# CGF v0 — counterfactual choice margins, CPU pilot
Goal: test incremental source attribution signal from contextual probability responses to fixed lexical alternatives. This is not proof of novelty, source-model probabilities, or a 0.76 candidate. DetectGPT perturbs texts, TRACE uses token transitions, ATLAS uses source-conditioned likelihood, and targeted counterfactual fingerprinting (arXiv:2608.08195) probes live endpoints, which NTL cannot do. Our scoped intervention is an alternative-choice distribution at the SAME masked position, over fixed sets of near-alternative discourse/function words, measured with a common frozen model. Alternatives are not guaranteed semantically interchangeable in all contexts. No paraphrasing claims.
Design decision: CPU RoBERTa-large frozen probe, no new model training, no GPU, no submission. Official train byte hash 40a22ce8d88c5f46feb4637a099db815bef5f713ffe53e89dbe1b7b21de77707, frozen fold mapping 94136d7dcb4689b0a8a21b742c20e886b865db67f5643c3402e6c1727b27f66d. 12 complete prompts each from Fold0 and remaining folds, 216 refs + 216 queries, chosen before scoring with seed 20261127. Existing development data, not fresh external validation. Compare A actual lexical counts; B A + observed masked log probability; C B + centered alternative log probabilities and observed-vs-other margin; D B + C response vectors shuffled within prompt independently for ref/query. Train-reference-only standardized nearest centroid, equal weighting per block, not gradient training. Record BA, coverage, per-class recall, paired changes and runtime. If C fails to beat both B and D by >= 0.03 BA, no scale-up of this exact recipe. Passing is preliminary only; need independent source, same-row champion errors, and more capable frozen model before any submission. No raw rows or IDs logged or published.
Implementation: core arithmetic and hash tests (local RED missing module, GREEN 4 passed); CPU workflow pulls train ephemerally and checks exact bytes and fold identity before model download. Full-repo test suite not run. Main unchanged.
