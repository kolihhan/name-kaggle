# SCaL-v0: Sibling-Contrastive Source Likelihood
Date: 2026-11-24. New standalone experimental lane, NOT the previously frozen `conditional-denoising18-v1` contract; do not mutate its promised Stage A/external-holdout scheme.

## Bottleneck and hypotheses
- Frozen official Champion: publicly scored 0.715, inherited strong multi-expert source. Our own PACE 18-way conditional histogram 0.1575 OOF vs same-input Global53 0.2182. PACE's conditional summary is not a generator-specific trained LM; GLM pair can carry strong binary signal (historical Global53 0.9433 two-way), but its global summaries do not identify 18 full classes.
- H1: proper source-conditioned **full-vocabulary masked-token** likelihood with source-specific learned low-rank residuals contains exact-label identity signal, compared with standard source-conditioned likelihood alone.
- H2: even with contextual reference states, output tokens/collection/protocol artifacts dominate; adding sibling-negative label contrastive loss does not generalize to prompt-disjoint texts.

## Single primary intervention
A frozen MIT RoBERTa-base masked LM, full 50,265 vocabulary, one forward pass per masked document; source residuals `W(z+B_m A z)+b+c_m`. Rank16. Shared A, B_m per 18 source labels and c_m per 18 source labels trainable; backbone, decoder W and b frozen. Train **proper full-vocab CE for the true model** in BOTH arms. In main SCaL arm add a sibling-conditioned counterfactual term `0.5 softplus(0.2 + logp_neg(token|context) - logp_true(token|context))`; control pure CE omits it. Deterministic family-sibling neg at each example, no adaptive hard-negative mining. This is our own experimental loss specification, inspired by but NOT a reproduction of ATLAS prefix/LoRA. ATLAS paper: https://arxiv.org/abs/2610.19583. It is not evidence of proprietary source probabilities.

## Fixed scientific protocol
- Official train.csv SHA256 `40a22ce8d88c5f46feb4637a099db815bef5f713ffe53e89dbe1b7b21de77707` (2699 rows, 18 labels, 150 prompts), prompt-wise fold mapping file SHA256 `94136d7dcb4689b0a8a21b742c20e886b865db67f5643c3402e6c1727b27f66d`. GitHub runner privately conveys **only SHA256-hashed prompt keys and their fold assignments** to Kaggle; no raw text/ID or label embedding in new Git code.
- RoBERTa-base revision `e2da8e2f811d1448a5b465c236feacd80ffbac7b`, safetensors only, `trust_remote_code=False`; frozen backbone. max_length=256, deterministic mask of up to 24 whitespace words / 15%; all subword pieces masked together, no unmasked target subpieces and no label/prompt leakage.
- **One prespecified fold (0) pilot**, train on other 4 folds only. Two arms SAME seed=20261124, SAME masked contexts, optimizer, batch, 2 passes over all train tokens, same initial state, only contrastive loss different. Shared rank=16, 2 epochs, token batch=64, AdamW adapter LR 0.0003 and bias LR0.001, gradient clip 1.0. Equal document and source class contributions, fixed no hyperparameter search.
- Score all 18 label-specific heads for same masked heldout target tokens with mean proper full-vocab logp, uniform class prior, argmax. Controls: pure source CE vs SCaL; independent direct 18-way frozen-state class LogisticRegression(C=1) on same masked document states (train-only); no expensive extra backbone.
- Record test class recall, paired rescues/regressions, BA, prompt-bootstrap conditional CI, truncation fraction, wall-clock, label/feature provenance. Do not compare this pilot BA directly with 0.715 Public; historical 0.367 sparse full-OOF is not matched. No output row text/IDs/token values/learned weights to public GitHub.
- Pilot success threshold: SCaL - pure CE >= +.03 BA on fold0 AND 95% prompt-cluster bootstrap lower bound >0; SCaL >= direct frozen-state CE baseline. If fails, STOP exact recipe and no second fold or Kaggle submission, do not tune after results. If passes, separate frozen 5-fold contract and source-independent transfer evidence before competition submission.
- No GPU if Kaggle allocation unavailable; internet restricted to pinned public MIT pretrained model. Private notebook; no official competition submission, no scheduler. Kaggle completion (including fast 3-row) isn't a scored test by itself. Do not claim source-adapter competitive gain until real actual labeled fold0 numbers exist.
