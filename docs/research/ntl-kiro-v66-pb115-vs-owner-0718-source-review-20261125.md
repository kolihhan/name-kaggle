## Exact new mechanism
1. PB115 combines **54 old sequence likelihood features** and **61 new token-aligned paired GLM-5.3/GLM-5.3-Flash score features**; training file includes all official 2699 rows (source code checks 115 cols and fits on competition train.csv). At inference only selected candidate texts with both GLM likelihood scores are featurized (time-budget selection unchanged).
2. At Kaggle run time, an **18-class classifier** is fitted on the official training set using LogisticRegression(`C=0.025`) plus three-seed LightGBM (55% LR/45% LGB). Separately **3-class [other, GLM-5.3, GLM-5.3-Flash]** LogisticRegression(`C=0.03`) + three-seed LightGBM is fitted (50/50 blend). This DOES train small classifier heads at inference, but not full pretrained language models.
3. The new 3-way `marginal_logodds_from_p3` produces a full-18 logit update that modifies **only the 2 GLM logit columns** (not relative logits of 16 non-GLM classes). Runtime `compute_hybrid_delta` uses `hybrid_alpha=0.25`, entropy matching and logit weight scaling for the 18-way and 3-way contributions.
4. `prefix_decisions.py` changes guarded Fable rescue from `base_argmax in GLM & post_argmax == claude-fable-5 & (after-before)>=.30 & after>=.25` into simply `base_argmax in GLM & post_argmax not in GLM`, a **materially broader protection rule** across all non-GLM predictions. This change may help some classes and harm others; it cannot inherit the +2/252 same-row result of our stricter Fable rule unchanged.
5. All 15 other emitted-code modules (including original inference, sibling residual and typography) are exact-identical to historical scorer. The public score gain is thus plausibly from the two altered stages and notebook-level plumbing, but cannot be specifically attributed to PB115, three-way marginal update, wider guard, or runtime stochasticity without controlled tests.

## Scientific judgement
- **Score is REAL, increment is SMALL**. A 0.722 scored notebook is a legitimate higher external reference than the owner's 0.718, but it is still **0.038 below the 0.760 goal**.
- The new **token-aligned, paired dual-GLM likelihood** is a substantive different measurement channel, not just retuning typography. The 115-feature discriminative heads and dynamic hybrid calibration need cross-source validation.
- Risk: serving/source mismatch in GLM target generations; current external 252 has already been spent; package complexity ~same as incumbent plus a dataset; hidden runtime mode may have fallen back to 54-D; broad Fable guard could regress other non-GLM classes; official-training fitted discriminative head isn't a clean OOF scientific test.
