# Phase C｜六个候选会怎样失败

[判断] 概率是一次冻结实现单独达到 Public 目标的主观估计。预期价值排序同时考虑可实现性、受影响样本数和实际成本。以下止损都是建议；公榜判据沿用用户给出的口径。

| 顺序 | 单项达标概率 | 失败方式 | 提前止损信号与便宜测量 |
|---|---:|---|---|
| N1 同题双向损失 | 12% | 学到完整训练组结构或仅因一般正则化获益；隐藏推理只有单段文字。 | 完整缺项掩码，逐行推理。真配对若不能胜过同算力的打乱配对，就停止以“同题机制”解释结果。 |
| N2 字符序列似然 | 5% | 学到题材、标点习惯或长度，冠军成员已覆盖这些错误。 | 在同样归一化、同折的一元对照上看救回与回退；信号仅来自少数题或与基础成员完全重叠时停止扩展。 |
| N3 跨表示二层读出 | 8% | 多个头重复犯错，或二层在已用过的 prompt 上过拟合。现成可验证输入不足，可行性排第三。 | 先算配对加权救回上限。上限低于目标差 .029，就不以该成员单独冲 .720；只有可嵌套交叉拟合的分数才用于训练二层。 |
| G2 歧义处查一次调用边 | 9% | 同名函数引入错误文件，定位正确也可能修错语义。 | 与词法定位使用相同文件名额，单列新命中、被挤出、无触发。没有可靠边时保持原候选，定位指标只用于判断检索。 |
| G1 可选的改前红、改后绿 | 7% | 断言可能根本没运行、环境错误可冒充红灯；强制验证耗尽时间。 | 记录真实命令与出口；只有原因吻合的红、同一断言在参考修复变绿才计命中。不能区分或无法保留首次编辑机会时退出此分支。 |
| G3 反证后再试另一个根因 | 5% | 第二补丁复现相同错误；测试无法选择，增加超时风险。 | 先测第二补丁独有 PASS 与选择器额外改错。没有可区分的两个补丁或剩余预算不足即回到原补丁。 |

[判断] 两项均无 P>15% 的单项。Gemma 需要至少净救 4/47 个原失败才能从 11/58 到 15/58；若别处回退还要更多。在6题存量对照中，0个空补丁，因此即使完美恢复空补丁也只能在这6题净加0题。2个可信错补丁、4个评分环境/题目不明；超时与补丁是否回收分开记录。隐藏时间截尾和各错误桶未提供，无法据此外推预算重分配的上限。
