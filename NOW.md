## BREAKTHROUGH BET — paired-prompt counterfactual model evidence (2026-11-10)

**Decision:** The user wants a **large, genuinely differentiated capability leap**, not repeated audits, marginal ensemble tuning, or copy→submit cycles. We select exactly ONE ambitious, falsifiable inference-only line: **Matched-Prompt Contrastive Fingerprinting (MPCF)**. It is an **experimental bet, not an achieved scientific breakthrough, a novel-publication claim, or a scored Kaggle result.**

**Core insight:** In external reference material, two *different exact-model sibling labels* responding to the **same prompt** can be differenced to suppress shared topic/prompt variation. For a frozen embedding `z`, paired A/B answers `a_p,b_p`, let `c_p=(z(a_p)+z(b_p))/2` and `d_p=z(a_p)-z(b_p)`. For a new query `x`, select reference pairs by query–centroid semantic similarity (no hidden prompt grouping); the per-pair *contrast* is `(z(x)-c_p) dot d_p / ||d_p||`. Aggregate a fixed top-k through a robust median. This estimates **pairwise A-vs-B differential evidence**, not an unconditional 18-way prediction. The mechanism needs **NO supervised fit, neural fine-tuning, Gaussian calibration, or test-set labels**. It uses paired reference examples plus an already-frozen pretrained encoder. The pure math module is [scripts/matched_panel_evidence.py](scripts/matched_panel_evidence.py), and synthetic invariants in [tests/test_matched_panel_evidence.py](tests/test_matched_panel_evidence.py). This has NOT been tested on real labeled rows or executed on GPU; synthetic invariants establish only sign/shape correctness.

**How it could beat stronger ensembles:** It is a *new conditional information source* computed from contrastive **matched reference responses**, rather than another bag-of-style features, batch Hungarian constraint, or a duplicate fitted sibling head. Only for ambiguous **same-family top-two** cases from a truly independent strong champion would it be allowed as candidate additional evidence. Preservation of high-confidence/provider-correct predictions is a design objective requiring proof, not guaranteed by simple gating.

**What the data actually support:** Existing authenticated public Oleg response corpus [Actions 42362668801](https://github.com/kolihhan/name-kaggle/actions/runs/42362668801) includes same-source/same-prompt exact-label pairs: GPT Luna–Sol 196, GPT Sol–Terra 199, GLM 200, but from SWEeper software-repair traces; target-length, served model, decoding settings and **collection protocol alignment are NOT established**. Its broad 13,642 rows are NOT equivalent to complete short-text 18-model matched panels; no all-18 pair availability is proven. The previously inspected Kaggle Benchmarks proxy 834 dataset had no qualifying exact same-request sibling control with matching requested length. An external cohort with usable **short (40–250 word), prompt-matched, protocol-documented** pairs from a different independent collection is not yet verified. Thus **scientific transfer and whole-stack competitiveness remain UNKNOWN**, and this program is NOT promoted to Kaggle.
