# Train-time within-prompt column cross-entropy, 2026-11-18

Frozen locally before feature extraction, fitting, or OOF prediction. The scientific proposal was recorded in Phase A, commit `a7fa9a4`. This is one CPU diagnostic on reused development folds.

**Question.** On new prompts from the official training collection, does adding a same-prompt model-to-response classification term improve a fixed row-independent, 18-label classifier? An alternative explanation is that a second classification term or its effect on the data-to-regularization ratio helps regardless of prompt identity.

**Data.** Use the 2,699 official training rows and the permanent Phase 1 five-fold `GroupKFold` assignment, aligned by row ID, prompt ID and target. Each fold reserves 30 entire prompts. SHA-256 for train is `40a22ce8d88c5f46feb4637a099db815bef5f713ffe53e89dbe1b7b21de77707` and for folds `94136d7dcb4689b0a8a21b742c20e886b865db67f5643c3402e6c1727b27f66d`. The official test set, existing prediction members, public scores and external cohorts are outside the input set.

**Fixed implementation parameters.** Each fold fits case-sensitive character TF-IDF (2–5 grams, minimum document frequency 2, at most 24,000 features, sublinear term counts, smoothed IDF, L2 normalization) and randomized 256-component truncated SVD (five power iterations, ten oversamples, seed 20261118) on its training texts only. L2-normalize projected rows. All arms share those matrices and a zero-initialized affine 18-class head. Use float64 full-batch Adam, 200 updates per arm and fold, learning rate 0.05, betas 0.9/0.999, epsilon 1e-8. Add `0.0005 * ||W||² / 2` to each loss, with an unpenalized bias. Fixed settings, one run, no search or early stopping.

| Arm | Training objective |
| --- | --- |
| C0 row | Mean 18-class cross-entropy across responses. |
| C1 matched | C0 plus mean column cross-entropy. For every observed (prompt, class), identify its response among that prompt's existing responses using the chosen class's logits. Equally weight all observed (prompt, class) pairs. Omit a missing response from every column denominator and omit its missing class from that prompt's column targets. All 18 logits remain eligible for the row loss. |
| Cs shuffled | Same objective as C1. Before fitting, independently permute the training responses of each class across that class's existing prompt slots, preserving class counts, group sizes and C1's loss scale. Use one fixed training-only permutation per class generated sequentially in sorted label order from seed `20261118 + fold_id`. |

**Evaluation.** All arms use row-wise `argmax(xW + b)` on the same held-out texts, with no prompt, position, other responses, or quota at inference. Pool each row's single OOF prediction and compute unweighted mean recall across the 18 classes. Report primary C1−C0 and specificity contrast C1−Cs. For each, calculate a paired percentile 95% interval over 10,000 replicates, seed 20261118, drawing 30 whole prompts with replacement within each of the five fixed folds. Recompute each class denominator in every replicate. Show all arms by fold, every true-class recall and exact rescue/regression count for the primary pair, and counts by true model family including family-only rescues/regressions. Store row predictions only locally outside the repository and publish aggregate outputs only.

**Interpretation.** Interval bounds describe variation across the evaluated prompts conditional on the fixed trained models. If the primary interval spans zero, this diagnostic cannot establish a gain. If C1 improves on C0 but the C1−Cs interval spans zero, improvement specifically from correct prompt matching remains unestablished. A positive interval can support an effect on this CPU head on these folds. Any inference about hidden balanced accuracy or the gap from .691 to .720 requires further independent evidence against the actual incumbent. No parameter, threshold, or arm will be selected using these results.
