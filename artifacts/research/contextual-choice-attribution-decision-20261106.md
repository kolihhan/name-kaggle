# Name That LLM — Can contextual choices identify sibling models?

**2026-11-06 MYT · Research decision · Design only**

**INFERENCE.** Prioritize **context-conditioned expression choices**. Estimate which of several interchangeable forms a model tends to use when its local context makes each form plausible. The test is whether those preferences add exact-model information beyond counts of the same choices and a full-text classifier on unseen prompts and a shifted generation condition. MAABench's released schema gives us a specific pair of competition labels to test.

## C. Independent diagnosis

**FACT.** In archived 18-label OOF, wrong-sibling macro error is **25.98%** and wrong-provider error **19.35%**. Provider-correct recall is **97.5%** for Gemini and **42.0%** for GLM. The centered head trades **1.82 points** fewer sibling errors for **1.71 points** more cross-provider errors. These are two different error regimes. In the view ablation, all three shared GPT-5.6 labels had at least as high FULL recall on the bank with lower overall macro BA. Different label coverage can create an apparent source penalty. A later source audit confirmed **125** candidate external rows share prompts with the actual A1 training split despite initial answer-text checks. [OOF decomposition](independent-conditional-attribution-diagnosis-20261106.md#full-18-label-macro-decomposition-new-analysis-of-archived-rows) · [Shared-label control](source-transfer-views-20261106/RESULT.md#family-level-mechanism-detail) · [Exact A1 overlap follow-up](https://github.com/kolihhan/name-kaggle/blob/66c7e1aef6cc87b3e085b2eee037989602232fac/artifacts/research/sibling-information-probe-v1/RESULT.md#exact-a1-training-split-follow-up--2026-11-06)

**INFERENCE.** The most actionable missing capability is to measure **how a model resolves a choice once the context creates that choice**. Word frequencies mix a model's preferences with how often a prompt or genre makes a particular expression appropriate. A document-mean readout could encode those preferences because its inputs are contextual, but its training objective supplies no explicit comparison against the other plausible realizations at each slot. A better inductive bias could recover evidence that the pooled readout uses inconsistently. The prefix is itself model-generated, so conditioning can discard genuine identity information carried by earlier choices. Dataset coverage, label fidelity and a stronger classifier remain competing explanations.

**FACT.** For two equally weighted labels, optimal text-only BA is $(1+\mathrm{TV}(P_a,P_b))/2$, with $P_a,P_b$ the observed passage distributions under the target prompt/protocol mixture. Equal distributions imply chance regardless of the representation. **UNKNOWN.** Their overlap on Kaggle, whether contextual preferences survive collection changes, and whether the public ensembles already extract the same information indirectly. The test below can establish usable endpoint evidence without resolving weights versus serving behavior. High source separability can arise from acquisition differences and says little about those limits. ## D. Competing directions

1. **Context-conditioned expression choices — primary.** Freeze a label-blind catalog of approximately interchangeable, same-role single-token continuations, such as *toward* and *towards* where both fit. Use one frozen causal LM to estimate which form is expected from the passage prefix. Fit a small regularized preference per model and choice type. In a binary slot, $\operatorname{logit} P_m(a\mid c,\{a,b\})=\log[q(a\mid c)/q(b\mid c)]+\theta_{m,a,b}$. Average the pairwise log-likelihood differences over observed slots and use the result as a feature, since slots within a passage are dependent. The shared reference is an offset and the model-specific normalizer makes the strength of evidence depend on context. The central assumption is that the reference captures enough shared context effects for the residual preferences to transfer. The observed passage stays intact and the reference supplies neither the unknown generator's logits nor simulated authored examples. **INFERENCE.** This can distinguish a model preference from a change in how often a genre affords a particular choice. The testable distinction from ATLAS is normalization over **alternative forms for one slot** with a shared frozen context model. Profiler contrasts **observed positions**, and GPT-who summarizes observed surprisal. Constituent-alternation studies and human authorship likelihood models establish nearby mechanisms, so publication novelty is **UNKNOWN**. Sparse coverage, a biased reference model, different contextual meanings, or protocol-dependent preferences can erase the advantage. An exact count control can falsify it. One small frozen decoder pass per passage and lightweight fits make an offline competitor plausible. [Constituent-order evidence](https://aclanthology.org/2025.naacl-long.126/) · [Authorial likelihood precedent](https://pmc.ncbi.nlm.nih.gov/articles/PMC12225838/) · [GPT-who](https://aclanthology.org/2024.findings-naacl.8/)
2. **Exact-label full-passage likelihood.** Fit an ATLAS-style surrogate condition per exact model so the whole text contributes, including content and structure. **FACT.** ATLAS's relative-likelihood clipping improved version-related shifts in its family benchmark. **INFERENCE.** Sibling labels could benefit from the same objective, particularly where sparse choice slots offer little evidence. The method itself is established, and V47 already uses an Atlas component. Exact-label adaptation needs clean examples for each label and scores multiple conditional views of every passage. It can learn source formatting or topical priors. The decisive test is held-out exact-sibling BA against an equally provisioned discriminative classifier on identical rows. A gain confined to family or in-domain scores fails the sibling claim. [ATLAS Table 5](https://arxiv.org/html/2610.19583v1#S5.T5) · [V47 score composition](ntl-0520-vs-lightning-v47-0666-mechanism-audit-2026-11-05.md#important-real-v47-probability-weights-not-just-the-title)
3. **Train on matched generation conditions.** Give a fixed learner equal support per exact model within each prompt × documented protocol block. Compare matched and label-balanced but deliberately unpaired draws of equal size from the same crossed corpus, with the same learner and wholly held-out prompts and a held-out protocol. That controls collection lineage and sample size while changing the association between labels and generation conditions. This changes the training distribution, extending the earlier crossed **evaluation** proposal, and isolates the value of coverage better than a new invariance loss. **INFERENCE.** It could help both provider and sibling errors if missing support or acquisition artifacts dominate. Its advantage fails if equal-count crossed training leaves transfer unchanged. The main cost is acquiring exact version and serving provenance across the 18 labels, especially where aliases can drift. Dataset matching is established methodology. The competition-relevant contribution would be clean coverage and its measured effect. [Crossed evaluation predecessor](generator-vs-channel-identification-decision-20261106.md) · [Source admission evidence](https://github.com/kolihhan/name-kaggle/blob/66c7e1aef6cc87b3e085b2eee037989602232fac/artifacts/research/sibling-information-probe-v1/SOURCE_ADMISSION.md)

## E. Research decision

**INFERENCE.** Choose direction **1**. It makes a distinct prediction with the lowest compute and data commitment, retains single-passage inference, and can be compared against a control using exactly the same observed tokens. Direction 2 has stronger published transfer evidence at family level but higher adaptation cost and an uncertain new contribution. Direction 3 gives the strongest intervention on provenance, but exact crossed training coverage is unverified and expensive. DCT-v3 addresses how to aggregate positions in a surrogate hidden sequence. Contextual choices target the alternatives available at a position, which gives a more direct test of the proposed signal.

The strongest counterargument is that local preferences are sparse or already recoverable from n-grams, while the real gap comes from training support and richer content. Treat a positive pair result as evidence for this representation, then require incremental improvement against strong full-text, generic-surprisal and full-token likelihood baselines before claiming a broad contribution. Even a two-point gain on two labels adds only **0.22 points** to 18-label macro BA if all other recalls stay fixed. Competitive upside depends on coverage across families and on preserving cross-provider recall. **UNKNOWN.** Neither the pair effect nor the broader lift has been measured.

## F. Smallest decisive test

**FACT.** The MAABench authors document `model`, `role` and `seed_id` for the exact versions. In their `version` and `joint` files, each seed has one row per newer version per family. Use **Claude Opus 4.8 vs Opus 5**, both Kaggle labels. The documented design implies **1,980 paired development seeds** in `maabench_version.jsonl` and **1,441 paired test seeds** in `maabench_joint.jsonl`, pending file-level verification. Here the exact labels stay fixed across splits. The Joint split shifts both domain and system instruction, so this is a joint transfer test with same-prompt comparisons within each split. The experiment measures transfer on passages with a 90–220-word target under one benchmark's collection, with coverage of Kaggle's shortest 40–80-word passages still **UNKNOWN**. [MAABench data card](https://huggingface.co/datasets/ming9999/maabench#statistics) · [Generation protocol](https://arxiv.org/html/2610.19583v1#A4)

1. **Prerequisites.** Obtain access under the dataset's gated CC BY-NC 4.0 terms. Pin the files, validate exact model labels and complete pairs by seed, and verify split disjointness and development lineage before evaluation. No raw files were inspected for this report. Use this as a research test. Competition eligibility and any use of the data, derived assets or results for a prize entry need separate clearance. [Data access and terms](https://huggingface.co/datasets/ming9999/maabench)
2. **Three fixed arms on the same rows.** Use char+word TF-IDF with class-balanced linear classification as the full-text anchor. Add a choice score with a context-constant offset in the control, and add the same score with the prefix-conditioned offset in the treatment. Set the contextual log-odds offset to zero in the count control and refit the same preference parameters. Both additions use the same eligible slots, label data, regularization and aggregation. Each adds one calibrated coefficient times its evidence to the same fixed anchor logit. Choose and pin one small pretrained base decoder, e.g. Qwen2.5-0.5B. Fit and calibrate using seed-disjoint partitions of `version` only. Exclude direct self-identification and formatting-only slots by a fixed rule in the choice arms. At test time each arm sees one response, with seed IDs used solely for pairing and uncertainty. Require the same eligibility predicate with either variant at a slot. Score every passage. Zero-slot rows fall back to the full-text score. [Reference model card](https://huggingface.co/Qwen/Qwen2.5-0.5B)
3. **One read of Joint.** Primary estimand is paired exact-model BA difference between contextual and count arms. Report both against the full-text anchor, per-model recalls, opportunity coverage by length, and the same contrasts by domain. Bootstrap paired seeds within domains. Advance only if the contextual arm beats both controls, its gain over the count arm is at least **2 absolute points** with a paired 95% interval above zero, and both held-out domains have positive point estimates over that count control. The two-point threshold is a proposed minimum useful effect for this pilot. Comparable gains from both choice arms support the choice features alone. A gain that survives the count control supports the contextual mechanism. An upper interval bound below two points falsifies a material gain on this panel. An interval spanning zero and two points is inconclusive. Sparse opportunity coverage is a feasibility failure for this representation on short passages.

**Decision boundary.** A positive result earns one independent replication with a second exact pair and different collection settings, followed by a predeclared incremental test against a strong 18-way baseline on admissible data. An adequately precise null closes this version of the mechanism. A blocked data prerequisite leaves the test unrun. This entry records a hypothesis and a test design.
