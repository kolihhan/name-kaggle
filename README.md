# Name That LLM — Kaggle

Working repository for the Kaggle competition **Name That LLM**: identify which of 18 language models generated each passage.

Competition: https://www.kaggle.com/competitions/name-that-llm

## Current state

Phase 1 establishes an honest, reusable validation contract before stronger modeling:

- official training data audited: 2,699 rows, 150 prompts, 18 models;
- deterministic 5-fold `GroupKFold` by `prompt_id`;
- zero prompt overlap between train and validation folds;
- baseline metric: balanced accuracy;
- best current classical baseline: character TF-IDF (1–5 grams) + LinearSVC, OOF balanced accuracy **0.3193**;
- hierarchical lab→model classification did not materially improve the baseline.

The fold assignment is deterministic and regenerated by `scripts/make_folds.py`. It was verified locally against the original frozen Phase 1 mapping: **2,699 / 2,699 rows identical**. All future experiments must reuse this generator / resulting `fold_id` values so scores remain comparable.

## Quick start

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt

# Preferred: use the official Kaggle zip you already downloaded
bash scripts/bootstrap_data.sh /path/to/name-that-llm.zip

# Recreate the exact Phase 1 folds
python scripts/make_folds.py
```

If no local zip is supplied, `bootstrap_data.sh` tries the Kaggle CLI and then a public transport mirror whose `train.csv` and `test.csv` were verified byte-for-byte against the uploaded official competition package using SHA-256. The mirror is never trusted without the hash check.

A manual GitHub Action, **Materialize official competition data**, can also place the verified official snapshot into `data/`.

## Validation contract

Do **not** use a random row split. Rows sharing a `prompt_id` must stay in the same fold. The hidden Kaggle test uses unseen prompts, so prompt-grouped CV is the local source of truth.

## Next experiment
