# Name That LLM — Kaggle

Working repository for the Kaggle competition **Name That LLM**: identify which of 18 language models generated each passage.

Competition: https://www.kaggle.com/competitions/name-that-llm

## Current state

### Phase 1 — frozen validation contract

- Official training data: **2,699 rows / 150 prompts / 18 models**.
- Validation: deterministic **5-fold `GroupKFold(prompt_id)`**.
- Prompt overlap between train and validation: **0 in every fold**.
- Metric: **balanced accuracy**.
- Best classical baseline: character TF-IDF (1–5 grams) + balanced LinearSVC, OOF **0.31930**.
- Hierarchical lab→model classification did not materially help.

The permanent fold mapping is regenerated by `scripts/make_folds.py`. It was verified against the original Phase 1 mapping: **2,699 / 2,699 rows identical**.

### Phase 2 — external data

The first usable external source passed the raw-data gate and improved the sparse frozen-CV baseline:

- Source snapshot: GPT + Gemini generations from `RohanExploit/kaggle-name-that-llm-top20`.
- Raw audit: **2,503 rows / 430 independent prompts / 8 exact competition labels**.
- Duplicate normalized texts: **0**.
- Exact overlap with official train: **0**.
- Maximum TF-IDF word 1–2 similarity to an official train passage: **0.166**.
- `model_seen` provenance blank rows: **0**.
- 40–250 word protocol coverage: **98.4%**.

Sparse frozen-CV ablation:

| Experiment | Balanced accuracy | Δ vs official-only |
|---|---:|---:|
| Official only | 0.31929 | — |
| Official + all 2,503 external rows | **0.34116** | **+0.02187** |
| Official + class-balanced 1,120-row slice | 0.33597 | +0.01668 |

This promoted the source only to a representation-transfer test. It did **not** establish that the data is universally helpful.

### Phase 3 — frozen ModernBERT representation gate

Frozen `answerdotai/ModernBERT-base` embeddings + balanced LinearSVC were evaluated on the same permanent folds.

| Condition | OOF balanced accuracy | Δ |
|---|---:|---:|
| Official only | **0.30224** | — |
| Official + 2,503 external rows | **0.29041** | **-0.01183** |

**Decision:** the 2,503-row external source **fails the encoder-stage admission gate**.

The strongest diagnostic is that recall fell for **all 8 / 8 labels directly covered by the external source**. This points to a representation/domain mismatch rather than a small aggregate fluctuation.

Do **not** include these external rows in the first trainable-encoder experiment. Keep them available for later targeted ablations.

See:

- `artifacts/phase3/FROZEN_ENCODER_CONTRACT.md`
- `artifacts/phase3/frozen_modernbert_ablation.json`
- `artifacts/phase3/RESULT.md`

The frozen encoder score itself does not decide whether fine-tuned ModernBERT works; Phase 3 isolates representation transfer and external-data effect only.

### Maniceet 7,753-row source

`maniceet/name-that-llm-openrouter-openai-generations` remains promising from its public metadata, but it has **not** passed our raw-row audit yet.

Verified access state:

- `KAGGLE_API_TOKEN` authentication succeeds;
- the same token can access the official `name-that-llm` competition API;
- Kaggle dataset API calls for this specific resource return HTTP 403 from both Kaggle CLI and `kagglehub`.

Treat the 7,753-row source as **blocked on resource-specific dataset access/consent**, not as verified training data.

## Canonical workflow

The repo source of truth is reusable code plus committed evidence, not inline experiment code hidden inside CI YAML.

```text
data/                    Official competition data and audited external snapshots
scripts/                 Reproducible audit / fold / experiment code
artifacts/phase1/        Frozen validation audit and baseline evidence
artifacts/phase2/        External-data reconnaissance, audits, ablations, access state
artifacts/phase3/        Frozen encoder contract, result, and decision
.github/workflows/       Execution wrappers plus a few one-shot historical diagnostics
```

Key scripts:

- `scripts/bootstrap_data.sh` — restore official competition data.
- `scripts/make_folds.py` — recreate the frozen grouped folds.
- `scripts/audit_gpt_gemini_external.py` — reproduce the 2,503-row external raw audit.
- `scripts/run_external_ablation.py` — reproduce the sparse official-only vs external-data ablation.
- `scripts/run_frozen_encoder_ablation.py` — reproduce the Phase 3 frozen ModernBERT A/B.


## Validation contract

Do **not** use a random row split. Rows sharing a `prompt_id` must stay in the same fold. The hidden Kaggle test uses unseen prompts, so prompt-grouped CV is the local source of truth.

External data is admitted stage by stage. An uplift under sparse TF-IDF does not automatically authorize the same source for encoder training. Data derived from official train prompts must be fold-isolated or excluded during model selection to avoid prompt-semantic leakage.

## Next experiment

Build the **official-only trainable ModernBERT baseline** under the permanent folds:

1. fine-tune the same encoder family on the four official training folds only;
2. score untouched official validation rows with balanced accuracy;
3. record all five folds plus per-model recall;
4. establish this baseline before reintroducing any external data;
5. only then compare LoRA/full fine-tuning and targeted external-data variants.

The 2,503-row GPT/Gemini source is **not** part of this first trainable baseline.
